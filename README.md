# Sinaliza

Plataforma de aprendizagem de Língua Brasileira de Sinais (Libras).

O projeto busca tornar o aprendizado de Libras mais acessível, interativo e prático, combinando conteúdos educacionais, exercícios e experimentação com visão computacional.

## Estrutura

- `apps/landing`: landing page de apresentação do projeto.
