# Direitos e permissões
Links externos legítimos são a estratégia inicial, sujeitos à verificação de destino. Acesso gratuito não equivale a licença aberta. Nenhuma autorização de reprodução registrada. Não baixar, incorporar, copiar, extrair frames, hospedar PDFs ou capas sem evidência específica. Usar capas tipográficas originais, identificadas como representação gráfica, sem imitar capa editorial. Não gerar retratos fictícios de pessoas reais.
Para cada asset registrar titular, autoria, URL, licença e versão, escopo, evidência, data, crédito e restrições. Se desconhecido, não renderizar. Para vídeos preferir link externo; embed somente após revisão dos termos. Para fac-símiles distinguir obra original e reprodução digital. Não coletar gravações de câmera no MVP. Revisar consentimento, privacidade e acessibilidade antes de qualquer coleta futura.
